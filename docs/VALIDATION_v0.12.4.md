# AIExplorer v0.12.4 검증 기록

## 검색 결과 정렬

- `일치도순`은 검색 엔진의 원래 결과 순서를 보존합니다.
- `드라이브·최상위 경로순`은 드라이브 또는 UNC 공유 루트, 첫 번째 폴더, 전체 경로 순으로 정렬합니다.
- `가나다순`은 현재 Windows 문화권의 대소문자 무시 문자열 비교를 사용합니다.
- `수정 날짜순`은 최신 수정 항목을 먼저 표시하고 날짜가 같으면 이름순으로 정렬합니다.
- 네 정렬 기준은 통합 결과와 빠른 이름·경로 결과에 동시에 적용되며 결과 내 재검색과 함께 사용할 수 있습니다.

## 검증 명령

```powershell
.\verify_source.cmd
```

위 명령은 소스 계약 검사, Release 빌드와 smoke test를 연속 실행합니다.
v0.12.4 검증에서는 경고 0개, 오류 0개와 전체 smoke test 통과를 확인했습니다.
