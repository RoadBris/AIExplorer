# v0.8.3 검증 기록

- 원인: AI 의미 후보 설명 자체에 `추출된 본문`이라는 표현이 포함되어 스모크 테스트가 본문 일치 근거로 오인했습니다.
- 수정: 의미 후보 설명을 `문서 전체 정보의 다국어 의미`로 변경했습니다.
- 회귀 검사: 의미 후보 설명은 `로컬 AI Multilingual E5`를 포함하고 `본문`, `OCR`, `파일명 일치`, `경로 일치`를 포함하지 않아야 합니다.
- 제한: Linux 환경에서는 Windows WPF/DirectML 스모크 실행이 불가능하므로 구조·정책 회귀 검사를 수행했습니다.
- `verify_source.cmd`가 NuGet 복원 전에 Windows PowerShell 사전 검사를 실행해 이 계약 불일치를 즉시 차단합니다.
