# AIExplorer v0.12.2 검증 기록

## 오탐 원인

기존 검색어 해석기는 `계정`, `로그인`, `인증`, `접속`을 하나의 의미 그룹으로
사용했습니다. 이 그룹은 관련 파일을 넓게 찾는 데에는 유용하지만, 동일한 목록을
파일 내부의 직접 단어 일치에도 사용하면서 `접속`만 있는 네트워크 점검표를
`계정` 내용 일치라고 잘못 표시했습니다.

## 수정 계약

- 넓은 의미 확장은 파일명 후보와 E5 의미 검색용으로 유지합니다.
- 파일 내부 근거는 별도의 `ContentEvidenceAlternatives`를 사용합니다.
- `계정`의 직접 내용 근거에서 `로그인`, `인증`, `접속`을 제외합니다.
- `account`, `credential`, `username`처럼 실제 번역·표기 변형은 유지합니다.
- 변형어가 일치하면 결과 설명에 검색어와 실제 일치 단어를 함께 표시합니다.
- E5 의미 후보는 검색어가 실제 본문에 있다는 뜻이 아니라고 명시합니다.

## 회귀 검사

- `네트워크 접속 상태 장비 점검 결과 정상`만 있는 엑셀은
  `네트워크 계정` 내용 후보가 되지 않습니다.
- `network account owner list`가 있는 엑셀은 `계정` 내용 후보가 되며
  결과 설명에 `실제 일치 ‘account’`가 표시됩니다.
- 기존 `로그인` 검색의 넓은 의미 후보에는 `account`가 계속 포함됩니다.

## 이 환경에서 실행한 검사

- `python3 tools/validate_source.py`
- Tree-sitter C# 전체 파일 구문 분석
- XAML XML·이벤트·정적 리소스 검사
- 동일 범위 지역 변수 중복 및 경고 오류 승격 계약 검사
- PowerShell UTF-8 BOM 및 CMD CRLF 검사
- 소스 압축 무결성 및 빌드 출력 제외 검사

현재 Linux 작업 환경에는 .NET SDK가 없어 Windows WPF 빌드와 스모크 테스트를
실행할 수 없습니다. Windows에서는 `verify_source.cmd`가 Release 빌드와 전체
스모크 테스트를 통과해야 `build_release.cmd`가 배포본을 생성합니다.
