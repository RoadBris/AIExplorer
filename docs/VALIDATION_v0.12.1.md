# AIExplorer v0.12.1 검증 기록

## 수정한 회귀 테스트

v0.12.0 테스트는 `계정 목록.xlsx`라는 별도의 정상 엑셀 후보를 만든 뒤
`IT팀_계정관리.xlsx`가 결과 전체의 무조건 첫 번째인지 검사했습니다. 그러나
테스트 이름과 실제 요구사항은 본문에만 `네트워크·계정`이 있는 잡음 문서보다
직접 파일명 단서가 앞서는지를 확인하는 것이었습니다.

v0.12.1에서는 다음처럼 검사합니다.

- `IT팀_계정관리.xlsx`의 실제 결과 순위를 찾습니다.
- `일반_참고자료` 아래 본문 잡음 문서 중 첫 결과의 순위를 찾습니다.
- 계정관리 파일의 순위가 첫 잡음 문서보다 앞서는지 비교합니다.
- 실패하면 두 순위와 상위 12개 결과의 이름·일치 표시·근거를 출력합니다.

정상 후보가 추가되거나 정상 후보끼리 순서가 달라져도 본래의 파일명 우선
정책이 유지되는 한 이 테스트는 실패하지 않습니다.

## 자동 구조 검사

- `python3 tools/validate_source.py`
- Tree-sitter C# 전체 파일 구문 분석
- XAML XML·이벤트·정적 리소스 검사
- 동일 범위 지역 변수 중복 및 경고 오류 승격 계약 검사
- PowerShell UTF-8 BOM 및 CMD CRLF 검사
- 순위 비교 보조 함수와 대상·잡음 상대 순위 계약 검사

현재 Linux 작업 환경에는 .NET SDK가 없어 Windows WPF 빌드와 스모크 테스트를
실행할 수 없습니다. Windows에서는 `verify_source.cmd`가 Release 빌드와 전체
스모크 테스트를 모두 통과해야 `build_release.cmd`가 배포본을 생성합니다.
