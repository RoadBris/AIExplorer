# AIExplorer v0.10.1 검증 기록

## 수정한 실패

`stl 파일을 찾아줘`는 `.stl` 확장자 조건으로 정상 해석됐지만, 제목 검색기가 핵심 단어가 없다는 이유로 원문의 `stl`, `파일`, `찾아줘`를 다시 제목 키워드로 만들었습니다. 제목 비교 단계에서는 확장자를 제거하므로 모든 STL 파일이 탈락했습니다.

구조화된 확장자·파일 종류·폴더 조건이 하나라도 있으면 원문 토큰을 제목 키워드로 복원하지 않도록 수정했습니다.

## 추가 회귀 계약

- `stl 파일을 찾아줘`: 제목과 무관하게 `.stl` 파일 반환
- `이미지 파일을 찾아줘`: 제목과 무관하게 이미지 파일 반환
- `폴더를 찾아줘`: 제목과 무관하게 폴더 반환
- 형식 전용 판별 조건과 위 세 동작을 교차 플랫폼 검사 및 Windows PowerShell 사전 검사에서 확인

## 검사 결과

- XAML·정적 리소스·이벤트 처리기 검사 통과
- 검색 정책·AI 번들·점진 검색·가시성 정책 검사 통과
- PowerShell UTF-8 BOM 및 CMD CRLF 검사 통과
- C# 전체 49개 파일 Tree-sitter 구문 분석 통과

현재 Linux 검증 환경에는 .NET 10 Windows WPF SDK가 없으므로 실제 스모크 테스트 실행은 Windows의 `verify_source.cmd`에서 수행해야 합니다.
