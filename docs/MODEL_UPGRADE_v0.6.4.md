# v0.6.4 모델 업그레이드

## 변경한 모델

- 텍스트: Nomic Embed Text v2 MoE Q4_K_M은 유지하되 저장 차원을 256에서 768로 확대
- 이미지: TinyCLIP ViT-39M/16 Text-19M Q4F16을 OpenCLIP ViT-B/32 LAION-2B INT8로 교체

## 자동 마이그레이션

모델 ID와 버전이 달라졌으므로 기존 의미·시각 색인은 새 모델과 섞이지 않습니다.
AI 업그레이드가 완료되면 이전 TinyCLIP 모델 파일을 정리하고, 검색 또는 자동
색인 과정에서 새 768차원 의미 색인과 OpenCLIP 시각 색인을 순차 재생성합니다.
원본 파일은 변경하지 않습니다.

## 예상 자원 사용

- 의미 모델: 약 344MB
- 시각 모델과 토크나이저: 약 157MB
- CPU 실행기 포함 전체 다운로드 예상: 약 620MB
- 의미 색인 한 항목의 벡터 데이터: 약 256바이트에서 약 768바이트로 증가
- 시각 추론: 기존 TinyCLIP보다 느리고 메모리 사용량이 증가하지만 동시 추론은 1개로 제한

## 첫 실행 권장 사항

업그레이드 직후 넓은 상위 폴더의 모든 이미지가 즉시 검색되는 것은 아닙니다.
앱을 켜 둔 상태에서 자동 색인이 진행되도록 두거나 같은 상위 폴더에서 검색을
반복하면 자식 폴더를 순환하며 시각 색인이 채워집니다.
