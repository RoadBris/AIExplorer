# AIExplorer v0.11.0 검증 기록

## 검색 순위 회귀 계약

- `네트워크 계정 관련 문서를 찾아줘`에서 `IT팀_계정관리.xlsx`를 파일명 후보로 유지합니다.
- `IT팀_계정관리.xlsx`는 본문에 `네트워크`와 `계정`이 모두 들어간 일반 참고 문서보다 먼저 표시됩니다.
- `계정관리문서` 폴더 안의 문서는 상위 폴더 단서로 검색 결과에 포함됩니다.
- 일반 `문서` 요청은 문서·스프레드시트·프레젠테이션 범주를 함께 검색합니다.
- 네 개의 핵심 단어 중 하나만 우연히 맞는 기존 약한 후보 제외 정책은 유지합니다.

## UI 회귀 계약

- 이름 입력 창은 `SizeToContent=Height`, 최소 높이 248, 크기 조절 가능한 창을 사용합니다.
- 통합 검색과 제목 검색 목록은 픽셀 스크롤, Recycling 가상화, 페이지 단위 앞뒤 캐시를 사용합니다.
- 이미지 결과는 미리보기 디코딩 전에 같은 높이의 공간을 확보합니다.
- 미리보기 파일은 검색 중 반복 취소·재디코딩하지 않습니다.

## 이 환경에서 실행한 검사

- XAML XML·이벤트·정적 리소스 검사
- 검색 순위·한국어 복합명사·스크롤·대화상자 구조 계약 검사
- PowerShell UTF-8 BOM 및 CMD CRLF 검사
- C# 전체 소스 Tree-sitter 구문 분석

현재 Linux 환경에는 .NET 10 Windows WPF SDK가 없어 실제 Windows 스모크 테스트는 `verify_source.cmd`에서 추가로 실행해야 합니다.
