# v0.8.1 검증 기록

## 이 작업 환경에서 실제 실행한 검사

- `python tools/validate_source.py`
  - XAML XML 구문
  - XAML 이벤트 핸들러 연결
  - 리소스 키
  - AI 번들 모델명·고정 버전·SHA-256 계약
  - PowerShell 5.1용 UTF-8 BOM
  - 검색 UX와 프로세스 종료 계약
  - 여러 검색어 중 한 개의 넓은 동의어만 맞는 본문 오탐 회귀 정책
- C# 소스의 문자열·주석 제외 괄호/대괄호/중괄호 균형 검사
- 최종 ZIP 중앙 디렉터리 및 모든 압축 항목 무결성 검사

## Windows 스모크 테스트에 추가한 회귀 검사

- `원천징수`처럼 단일 업무 용어는 E5 의미 비교를 실행하지 않음
- 파일명 정확 일치가 E5 의미 후보보다 먼저 표시됨
- 관련 없는 WireGuard 문서가 원천징수 결과에 포함되지 않음
- 검색 실행 중 새 이미지 임베딩 호출이 발생하지 않음
- 캐릭터 고유명 문구가 일반 캐릭터 문구보다 실제로 상승한 후보를 우선함
- 미색인 위치를 사전에 감지함
- `일단 검색`이 색인을 만들지 않고 파일명·경로를 직접 확인함
- 여러 검색어 중 한 개만 본문에 맞을 때 본문 후보에서 제외됨
- 낮은 본문 커버리지가 E5의 `AI 후보` 배지를 덮어쓰지 않음

## 이 작업 환경에서 실행하지 못한 검사

현재 작업 환경은 Debian Linux이며 Windows WPF/DirectML 실행 환경과 .NET 10 SDK가
설치되어 있지 않습니다. 따라서 다음 Windows 명령의 실제 통과 여부는 이 기록에
포함되지 않습니다.

```cmd
verify_source.cmd
```

이 명령은 Windows에서 다음 순서로 실행됩니다.

1. NuGet 복원
2. Release 빌드
3. `AIExplorer.SmokeTests` 실행

실제 배포용 ZIP을 만들기 전에는 Windows PC에서 `verify_source.cmd`를 통과시켜야
합니다.
