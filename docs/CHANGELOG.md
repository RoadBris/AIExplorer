- 미리 등록되지 않은 `.ppk`, `.pem` 및 임의 확장자를 점 표기 검색 조건으로 해석합니다.
- 파일명의 확장자도 제목·메타데이터 검색 대상에 포함해 `pem 파일` 같은 검색으로 특수 형식을 찾습니다.
- 등록된 문서 형식에 한정하지 않고 `*`로 수집된 모든 일반 파일을 확장자·이름·경로 근거로 검색합니다.
- `aws ssh키를 찾아달라`에서 명령형 표현을 제거하고 `ssh키`를 `key`·`ppk`·`pem` 등 영문 파일명 의미로 확장합니다.
- 제목 검색도 다국어 관련 표현을 사용하되 `key`가 `monkey`의 일부로 맞지 않도록 영문 동의어는 토큰 단위로 판정합니다.
- 의미 AI 안내 문구의 부정 표현에 포함된 `본문` 한 단어 때문에 정상적인 AI 후보 테스트가 실패하던 문자열 계약 충돌을 수정했습니다.
- 낮은 본문 커버리지 회귀 검사를 단순 문자열 포함 여부가 아니라 `SearchEvidenceKind.SemanticCandidate`와 직접 내용 근거 표식으로 판정합니다.
- `파일 본문에서`, `엑셀 시트·셀에서`, `OCR에서` 등 실제 직접 근거만 구분하는 공용 테스트 보조 함수를 추가했습니다.
- 의미 AI 설명을 `검색어를 파일에서 직접 확인했다는 뜻은 아닙니다`로 바꿔 직접 일치와 의미 추정을 더 명확히 구분했습니다.
- 취약한 `Reason.Contains("본문")` 검사가 다시 추가되면 교차 플랫폼 소스 검증과 Windows 사전 검사가 즉시 실패합니다.

  비활성화하도록 변경
- `로그인` 의도를 `account`, `계정`, `credential`, `username` 등과 함께
  해석해 우회적인 한영 혼합 질의 보강
- 파일명에서 모든 의미 단서가 확인된 결과가 설치 폴더의 본문 단어 일치 결과에
  밀리지 않도록 점수 체계 재조정
- 메타데이터 색인이 잘렸을 때 파일 형식뿐 아니라 일반 문장 파일명 검색도
  메모리 제한형 정밀 재탐색으로 보완
- 드라이브 색인 시 현재 사용자의 바탕 화면·문서·다운로드·사용자 폴더를 우선
  처리하고 기존 메타데이터·본문 색인을 자동 갱신
- AI 의미 색인 대상을 본문 추출 문서에서 모든 파일의 파일명·상대 경로까지 확대
- 최근 파일 고정 순서 대신 현재 질의와 가까운 파일부터 의미 벡터를 만들도록
  변경하고, 저사양 PC용 검색당 새 변환량을 750개에서 256개로 축소
- 본문 일치 잡음 320개가 있어도 `mullvad_account...` 파일이 1위가 되는지,
  색인 상한 밖에서도 복구되는지, 본문 미지원 파일에 AI 근거가 붙는지 회귀 검사

## v0.3.0

- TXT·Markdown·로그·설정 파일·소스 코드의 본문 추출 및 범위별 압축 색인 추가
- DOCX·PPTX·XLSX·HWPX·ODT·ODS·ODP 컨테이너의 XML 본문 추출 추가
- BM25 계열 점수로 파일명과 무관한 본문 단어 일치를 검색 결과에 반영
- 일반 표현인 `로그인 코드`를 소스 코드 파일 요청으로 오인해 TXT를 제외하던 문제 수정
- 선택 설치형 Multilingual E5 Small IQ4_XS 다국어 의미 검색 추가
- llama.cpp Windows x64 CPU 실행기의 루프백 전용 임베딩 API 연동
- 모델·실행기 사용자 확인 설치, SHA-256 무결성 검증, 설치 진행률과 취소 추가
- 의미 벡터를 8비트로 압축 저장하고 검색당 최대 750개씩 점진적으로 색인
- 로컬 실행기에 임시 API 키를 적용하고 5분 미사용 시 모델 메모리 자동 해제
- 이름·경로·파일 형식·본문·의미 유사도를 혼합하며 AI 실패 시 본문 검색으로 자동 복귀
- 파일명과 무관한 Mullvad 본문 검색 및 한영 교차 의미 검색 통합 회귀 테스트 추가
