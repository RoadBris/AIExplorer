# AIExplorer v0.9.9 validation

## 변경 계약

- `Hidden` 및 `System` 속성 항목은 사용자 탐색과 모든 검색 색인에서 제외됩니다.
- 이름이 `~`로 시작하는 파일과 폴더는 제목 검색, 직접 탐색, 메타데이터 및 본문 색인에서 제외됩니다.
- 기존 캐시 검색은 SMB 재연결보다 먼저 실행되며 현재 루트 상태를 동기식으로 조회하지 않습니다.
- 공유 폴더 연결 후 최대 2,000개 항목의 제한된 직접 탐색으로 AI 결과 영역을 먼저 채웁니다.
- 무거운 의미·시각 AI 분석은 빠른 후보 표시 이후 실행됩니다.

## 환경 제한

현재 Linux 검증 환경에는 .NET 10 Windows WPF SDK와 Windows SMB 환경이 없어 실제 Windows 빌드 및 런타임 검색은 실행하지 못합니다.
