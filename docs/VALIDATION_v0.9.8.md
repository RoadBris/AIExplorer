# AIExplorer v0.9.8 validation

## 변경 계약

- 경로 입력칸 바로 오른쪽에 현재 경로 즐겨찾기 버튼이 있습니다.
- 버튼은 기존 즐겨찾기 등록 로직을 재사용합니다.
- 이미 등록된 경로에서는 버튼이 비활성화됩니다.
- 검색 범위 ComboBox의 기본 선택은 `현재 폴더와 하위 폴더`입니다.
- UNC 경로의 즐겨찾기 가능 여부 판단은 네트워크 응답을 동기 대기하지 않습니다.

## 환경 제한

이 환경에는 .NET 10 Windows WPF SDK가 없어 실제 Windows 빌드는 실행하지 못했습니다.
정적 XAML/C# 구조 검사와 배포 압축 무결성 검사를 수행합니다.
